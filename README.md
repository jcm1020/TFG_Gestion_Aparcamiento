# RAMA CODIGO
Rama del desarrollo principal para actualizar el codigo con una nueva propuesta de Base de Datos mas sencilla y enfocada a la privacidad.
La propuesta anterior registraba imagenes y objetos reconocidos ademas de alertas.
Ahora se pretende que estos datos procesados no permanezcan nada mas que brevemente en la memoria del sistema para obtener los datos necesarios.
De mantener permanencia alguno de estos datos, solo lo podra visualizar el administrador y solo algunos datos o imagenes para depuracion en la fase de desarrollo.
