\section{Resumen General de Objetivo}

SIGESAI Sistema de Gestión de Aparcamientos Inteligente, sistema de detección de objetos en tiempo real mediante cámaras IP Hikvision, usando la biblioteca YOLO de Ultralytic sobre GPU NVIDIA RTX 4090, con interfaz Django, dashboard de monitorización en un servidor Linux.

\textbf{Tarifa de desarrollo}: 50\,\euro{}/h (desarrollador Django/Python mid-level, mercado España 2026).

\section{Despliegue}

Todo en un mismo servidor: aplicación Django, base de datos PostgreSQL, YOLO GPU y captura de cámaras Hikvision.

\begin{itemize}
	\item \textbf{Ventajas}: coste menor, gestión simplificada, mantenimiento centralizado.
	\item \textbf{Inversión inicial}: \textbf{27.530\,\euro{}} (22.000 + 3.530 + 2.000).
	\item \textbf{Mantenimiento anual}: 15.600\,\euro{}.
\end{itemize}
